## Overview

DocMind is a privacy-first RAG application that lets users upload PDFs and chat with them entirely on-device - no external API calls. It runs a local Mistral 7B model and a hybrid retriever, keeping responses under 2 seconds across 10,000+ indexed chunks.

## Key Features

- **Hybrid retrieval**: A 70/30 weighted fusion of FAISS semantic search and BM25 keyword matching for accurate results across large documents.
- **Smarter chunking & reranking**: Sentence-aware recursive chunking plus cross-encoder reranking improved answer relevance by ~25%.
- **Fast repeat ingestion**: A content-hash embedding cache cut repeat ingestion time by 40-60%.
- **Private by design**: A decoupled FastAPI + Streamlit app with source citations and zero external API calls.

## Technologies Used

- **Python, Mistral 7B** - local LLM inference
- **FAISS + BM25** - hybrid retrieval
- **Sentence Transformers** - embeddings and cross-encoder reranking
- **FastAPI + Streamlit** - backend API and chat interface

## Outcome

DocMind delivers accurate, cited answers over private documents in under 2 seconds, with no data ever leaving the machine - demonstrating end-to-end ownership of a modern RAG system from retrieval to deployment.
